# Materials library

The library provides compositions and densities that can be loaded into a calculation with their provenance attached. Its rule is simple: **every number must say where it came from, or say plainly that it is untraced.** A wrong entry with a plausible citation is worse than a missing one. The loader therefore refuses any entry whose claims go beyond its evidence.

It is not, and cannot be, exhaustive. Ceramics, glasses and cements number in the tens of thousands, and every publication reports its own batch. The library aims for a **defined, checkable coverage** that grows only through verified additions.

## Current contents

| Dataset | Entries | Composition | Density | How it got here |
|---|---|---|---|---|
| NIST SRD 126, Table 2 | 47 | NIST elemental mass fractions | NIST value, **sourced** (NIST notes some are only nominal) | Parsed by `tools/import_nist_table2.py`; URL, DOI, retrieval time and page hash recorded |
| Stoichiometric phases | 95 | Exact from the chemical formula or designation | Typical value, **unverified** | Generated by `tools/build_stoichiometric_ceramics.py` |

The stoichiometric set covers oxide ceramics (alumina, zirconia and its 3Y/8Y designations, magnesia, spinel, mullite, zircon, rare-earth oxides), nuclear ceramics (UO₂, ThO₂), silicates and bioceramics (cordierite, forsterite, hydroxyapatite, β-TCP), electroceramics and ferrites (BaTiO₃, LiNbO₃, hexaferrites, YIG), scintillator hosts (YAG, LuAG, GGG, LSO, BGO, tungstates, fluorides, NaI, LaBr₃), non-oxide ceramics (SiC, Si₃N₄, AlN, BN, B₄C, transition-metal carbides, nitrides and borides, MAX phases), semiconductors and cement phases.

**Independent cross-check.** Eleven NIST materials are exact stoichiometric compounds (GaAs, CdTe, CaF₂, LiF, CsI, HgI₂, CaSO₄, Li₂B₄O₇, MgB₄O₇, Gd₂O₂S, H₂O). The test suite compares NIST's tabulated mass fractions with those our formula parser derives. The worst disagreement is 3.4 × 10⁻⁵, consistent with revisions to standard atomic weights since 1995. Both the importer and the parser are therefore checked against a source neither of them wrote.

## Provenance tiers

| Tier | Required evidence |
|---|---|
| `reference_data` | A dataset block with URL, DOI, retrieval time and SHA-256 of the parsed source. Generated by a script, never edited by hand. |
| `stoichiometric` | A formula the engine can parse. Its density must be `unverified` unless a literature source for the density is attached. |
| `literature` | A DOI, a **locator** (table, figure or page), the DOI's resolved metadata, and the name of the person who compared the values with the paper, with the date. |

Each density also has a `status`. `sourced` means it comes from the entry's source. `unverified` means it does not, and then the note must say so. The API reports this status for every entry so the interface can prompt for a measured density.

## Adding a journal composition

1. Resolve the DOI and copy the output:

   ```
   python tools/verify_doi.py 10.xxxx/yyyy
   ```

   This proves the DOI exists and records its title and year. It does **not** check the numbers.

2. Add the entry to a file in `xray_workbench/materials/data/`, for example `literature_glasses.json`:

   ```json
   {
    "schema_version": 1,
    "dataset": {"id": "literature-glasses", "title": "Glass compositions from the literature",
                "license": "Compositions are factual data; cite the original publications."},
    "entries": [{
      "id": "lit-author2024-sample-b3",
      "name": "Bismuth borosilicate glass, sample B3 (Author et al. 2024)",
      "category": "glass",
      "tier": "literature",
      "composition": {"basis": "mole", "components": [
        {"formula": "Bi2O3", "fraction": 30}, {"formula": "B2O3", "fraction": 50},
        {"formula": "SiO2", "fraction": 20}]},
      "density": {"value_g_cm3": 5.12, "kind": "measured", "status": "sourced",
                  "note": "Archimedes method, as reported."},
      "literature": {
        "doi": "10.xxxx/yyyy",
        "locator": "Table 1, sample B3",
        "verification": {
          "doi_resolved": { "...": "paste the output of tools/verify_doi.py here" },
          "values_checked_by": "Your name",
          "values_checked_on": "YYYY-MM-DD"
        }
      }
    }]
   }
   ```

3. Transcribe **nominal** (batch) and **analysed** compositions as separate entries when a paper reports both. Keep the paper's basis (mol% or wt%); do not convert by hand.

4. Run `python -m pytest tests/test_materials.py`. Every entry must load and must produce finite physics.

Compositions and measured densities are factual data and may be cited. Do not copy tables wholesale from a source whose licence forbids reuse; transcribe the values you need and cite the paper.

## Candidate sources for later imports

These still need licence and provenance review before any import:

- **SciGlass** — large glass composition–property database, since released openly. Check the licence and version.
- **Materials Project** — CC BY 4.0 crystalline compounds. Its densities are *computed* (DFT) and must be labelled as such, never as measured.
- **ICSD / Pearson** — crystallographic densities, but licensed; they cannot be redistributed.
- **NIST ceramics data** and standards (ASTM, ISO) for designated compositions.

## API

```
GET /api/materials?q=zirconia&category=oxide_ceramic&tier=stoichiometric&verified_density=false
GET /api/materials/{id}?thickness_mm=2
```

The detail response includes the full source block, the density status and a `layer` object that `/api/calculate` accepts directly.
